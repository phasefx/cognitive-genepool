### Part 5: The Swap (Multi-class Intervention)

**If a monster is active, the fix is rarely "try harder." It's changing the party composition.**

**Procedure:**

1. **Identify the Lead:** "The __________ is currently driving."

2. **Identify the Monster:** "Because they're stressed, we're stuck in __________."

3. **Call for Multi-class:** "This class cannot solve this with more of itself. We need the __________."

4. **Execute the Class Move:**

| Class | The Move |
|:------|:---------|
| Wizard | Analyze — build a model, find the pattern |
| Ranger | Scout — go look, gather signal, trust the gut |
| Bard | Reframe — tell a different story, shift the lens |
| Artificer | Build — create a scaffold, tool, or system |
| Paladin | Commit — pick a version, hold the line, ship it |
| Rogue | Question — check the edges, test the assumptions |

### Part 8: Party Cohesion Check

*The goal isn't to "be" one class. It's party cohesion.*

**Signs of good cohesion:**
- [ ] I can notice which class is driving
- [ ] I can swap leads when the situation changes
- [ ] I have at least 3 classes above Level 2
- [ ] I know my stress responses and can catch them
- [ ] I can name what my benched class costs me

**Signs of capture:**
- [ ] One class is *always* driving
- [ ] I can't imagine responding differently
- [ ] Swapping feels impossible or "not me"
- [ ] I defend my current mode instead of evaluating it
