### 3) Weather Check (don't self-blame first)

**Is this mostly:**

- [ ] **Structural** (resources, environment, incentives)
- [ ] **Social** (coordination, audience, pressure)  
- [ ] **Cognitive** (model, story, interpretation)

*If Structural → stop. Change the world, not yourself.*

---

### 4) Monster Tell (pick the first that fits)

- Rebuilding the foundation instead of finishing → **Reboot Loop**
- Defending a tool/process over the outcome → **Ossified Scaffold**
- Narrow target, ignoring collateral damage → **Berserker**
- Story-defense over data → **Captured Narrator**
- Signal seen, no lever to pull → **Cassandra**
- "Secret patterns" justifying fear → **Paranoid Generator**

---

### 5) One Counter-Move (10 minutes)

*Pick one. Do it. Not all. Not perfect.*

- **Paladin:** Finish line — write it down + tell someone
- **Ranger:** External signal — ask a human / run a tiny test / touch grass
- **Wizard:** Falsify — write what would prove you wrong
- **Rogue:** Delete — imagine the tool didn't exist
- **Bard:** Rename — say the real goal out loud

---

### 6) Exit Gate (3 checks → 1 action)

**Before thinking more:**

1. **Biology:** Do I need sleep / food / movement?
2. **Substrate:** Is this a toxic environment or a missing lever?
3. **Jargon:** Can I say this without game words?
