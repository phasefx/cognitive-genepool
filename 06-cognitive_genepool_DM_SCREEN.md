## 🎯 THE TARGETING MATRIX

**STEP 1:** Find the **Interface Level** (Row) where the system listens. **STEP 2:** Select the **Intervention Target** (Column) you want to change. **STEP 3:** Check the **Risk** (Cell).

| Interface Level | World-Change (Constraints) | Map-Change (Signals) | Goal-Change (Values) |
| ----- | ----- | ----- | ----- |
| **L3: Reasoning***(Language, Laws)*⚠️ Slow / Low Fidelity | **Social Inscription***(Laws, Contracts)* | **Reframing***(Metaphor, Debate)*✓ Fast / High Drift | **Persuasion***(Value Logic)*☠️ Risk: Justification |
| **L2: Training***(History)*✓✓ Durable | **Niche Construction***(Gyms, Defaults)* | **Shaping / Cues***(Notifications)*✓ Context-Dependent | **Reward Design***(Incentives)*☠️ Risk: Goodharting |
| **L1: Setpoints***(Parameters)*✓✓ Hard Constraint | **Supply Chain***(Resource Control)* | **Gain Control***(Sensitivity)*⚠️ Homeostatic Fightback | **Parameter Reset***(Thermostat Dial)*☠️ Risk: Oscillations |
| **L0: Physical***(Hardware)*✓✓ Permanent | **Morphology***(Architecture)* | **Sensor Ablation***(Blinders)*✓ Info Bottleneck | **Lobotomy***(Lesioning)*☠️ Risk: System Death |

**LEGEND:** ✓ **Standard:** Good leverage point. ✓✓ **Critical:** High leverage / Durable. ⚠️ **Caution:** Resistance or decay likely. ☠️ **Backfire Risk:** Do not attempt without safety rails.

## 🛠️ DEBUGGING FLOWCHART

**1\. DIAGNOSE THE INTERFACE**

* *Does it respond to arguments?* → **L3 (Reasoning)**  
* *Does it respond to repetition?* → **L2 (Training)**  
* *Does it respond to error signals?* → **L1 (Setpoints)**  
* *Does it respond only to force?* → **L0 (Physical)**

**2\. DIAGNOSE THE FAILURE**

* *Persuasion feels good but nothing moves?* → You are arguing with a **Setpoint (L1)**.  
* *Behavior changes but meaning collapses?* → **Map Lag** (Goodharting).  
* *System optimizes harder after punishment?* → You fed it **Reward (L2)**.  
* *Nothing works?* → **Substrate Lock**. Replace or Exit.

**3\. SELECT THE INTERVENTION**

* *Need fast results?* → **World-Change** (Constraints).  
* *Need deep results?* → **Goal-Change** (but check the ☠️).  
* *Need new options?* → **Map-Change** (Reframing).

## ☠️ BACKFIRE CHEATSHEET

| The Move | The Backfire | Why? |
| :---- | :---- | :---- |
| **Arguments vs. Values** | **The Justification Loop** | System 2 is recruited to defend the goal, not update it. |
| **Incentives vs. Proxies** | **The Goodhart Spiral** | System optimizes the metric, destroys the intent. |
| **Spoofing vs. Homeostasis** | **The Snap-Back** | System fights the fake signal to restore equilibrium. |
| **Force vs. Regeneration** | **The Scar Tissue** | Healing mechanisms create fibrosis (see: *Cirrhotic Liver*). |

**⚠️ DIAGNOSTIC HEURISTIC:** Monsters are **Verbs**, not Nouns. A system isn't *evil*; it is performing a loop. Ask: **What is it optimizing?** and **What can it see?**

## 📡 THE LIGHTCONE SCATTERPLOT (Archetypes)

*Diagnostic: Where does the system fall on Care (Resolution) vs. Competence (Intensity)?*

**DISCERNMENT SCALE-CHECK**: Before placing a system on the Resolution axis, ask:
    * "Is the resolution matched to the problem?"
        - Are you measuring microns to build a barn? (Too High / Analysis Paralysis)
        - Are you using a subway map to dig a well? (Too Low / Wrong Map)

```text
      HIGH INTENSITY (God-Tier Power)
            ▲
      THE   │   THE ZOMBIE
    TORNADO │   BERSERKER
(Panic, Mob)│ (Metric Maximizer)
            │
────────────┼────────────▶ HIGH RESOLUTION (Seeing)
            │
   THE ROCK │   THE CASSANDRA
(Legacy Code│ (The Screaming Void)
  Sunk Cost)│
            ▼
       LOW INTENSITY (Powerless)

```

**The Center (The Target State):**

* **The Architect / Sage:** Balances structure and goal. Holds High Resolution without losing control, acts with Intensity without losing sight of the broader map.

**The Quadrants:**

* **Top Right (High Power + High Vision):** *Optimization without wisdom.* The system sees the target perfectly and crushes everything else to hit it.
* **Top Left (High Power + Low Vision):** *Destructive force without strategy.* Panic spirals, viral content, mobs. Energy moving fast with no map.
* **Bottom Right (Low Power + High Vision):** *Awareness converted to stress.* Seeing the train coming but tied to the rails. Heat death of agency.
* **Bottom Left (Low Power + Low Vision):** *Inertia.* Systems that resist change because they neither see the need nor have the energy. Legacy code, sunk costs.

---

**Ranger's Note:** This visualizes the "Iron Triangle" constraint mentioned in the SRD—you usually sacrifice Resolution to get Intensity, or Intensity to get Resolution. The goal is not to be in the corners; it's to navigate toward the center.

## 🔍 INSCRIPTION DEPTH CHECK

*How hard will it be to change this?*

1. **SURFACE (Reasoning):** "We agreed to do X." → **Easy.** (Change the agreement).  
2. **HABIT (Training):** "We always do X." → **Medium.** (Requires friction/reshaping).  
3. **NORM (Social):** "People like us do X." → **Hard.** (Requires social coordination).  
4. **ARCHITECTURAL (Physical):** " The building makes us do X." → **Very Hard.** (Requires demolition).

## 🧪 THE "IS IT REAL?" TEST (Regime Check)

*Before you panic, check the existential status of the monster.*

* **REALIZED:** It is running code *right now*. (The server is crashing).  
* **REACHABLE:** It isn't running, but we have the resources to build it. (The prototype).  
* **CONCEIVABLE:** We can imagine it, but no path exists yet. (The sci-fi fear).  
* **INCONCEIVABLE:** We can't even point at it.

**Rule:** Do not treat **Conceivable** threats as **Realized** emergencies.
