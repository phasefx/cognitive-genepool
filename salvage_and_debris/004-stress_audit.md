# Stress Audit: The Cognitive Genepool

## Executive Summary

The term "stress" was used in **5 distinct ways** across the documents, with some overlap and occasional slippage. To align with Levin's framework, we now distinguish between:

1. **Stress as Perturbation** (Levin-compatible, control-theoretic) — what tests whether a system maintains its goal state
2. **Stress as Signal** (dashboard/telemetry) — useful information about misfit between model and reality  
3. **Stress as Load** (waste heat) — resource drain when signal persists without resolution
4. **Stress as Felt Sense** (operational qualia) — for systems with qualia, the texture of "stuck"
5. **Stress-testing** (methodological) — deliberately perturbing to test robustness

The key insight from the operational qualia stance: "felt sense" doesn't require human-style phenomenology. A liver has a "dashboard" too — biochemical signals that present the state of the system. This makes the framework Levin-compatible while preserving phenomenological richness for systems that have it.

## Terminology Summary (For Reference)

| Term | Definition | When to Use |
|------|------------|-------------|
| **Perturbation** | External or internal force that pushes system away from goal state | Substrate-neutral, Levin-compatible, control-theoretic |
| **Stress signal** | Detection of gap between model/goal and reality | When stress is informative, useful telemetry |
| **Stress load** | Sustained resource cost of unresolved perturbation | When discussing burnout, waste heat, resource depletion |
| **Stress (felt sense)** | The subjective texture of "stuck" for systems with qualia | When discussing phenomenology, human experience |
| **Overload** | When a mode/class exceeds capacity | PHB class failure modes |
